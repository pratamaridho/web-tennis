# Audit Anti-Slop #001 — Bagan Turnamen

- **Tanggal**: 2026-10-01
- **Target File**: `src/views/BracketView.tsx`, `src/components/bracket/PublicLiveBracket.tsx`
- **Tujuan**: Memastikan halaman Bagan Turnamen mematuhi seluruh standar Craftsmanship (C-1 s.d C-5), aturan Hard Gate, Purpose-Gate, dan Quality Locks dari pedoman Anti-Slop (`SKILL.md`).

---

## Daftar Temuan (Numbered Findings)

### 1. [HIGH] R-27 — UI States (Error State Belum Tersedia)
- **Komponen**: `PublicLiveBracket.tsx` (baris 74–76, 99–103)
- **Alasan**: Ketika koneksi fetch API `/api/tournaments` atau `/api/tournaments/[id]/bracket` mengalami kegagalan (network error / 500), UI langsung mengasumsikan bagan kosong (`!hasMatches` / "Bagan Belum Dibuat") tanpa menampilkan Error State khusus dengan tombol coba lagi (Retry). Aturan R-27 mewajibkan setiap komponen data memiliki 3 state: *Empty*, *Loading*, dan *Error*.

### 2. [HIGH] R-32 — Aksesibilitas Keyboard pada Kartu Match Interaktif
- **Komponen**: `BracketView.tsx` (baris 330–385, 417–460, 637–677)
- **Alasan**: Kartu pertandingan babak eliminasi di kanvas diagram menggunakan elemen `div` dengan event `onClick` tanpa `role="button"`, tanpa `tabIndex={0}`, dan tanpa penanganan tombol `Enter`/`Space`. Pengguna navigasi keyboard tidak dapat memilih pertandingan untuk melihat panel inspeksi detail.

### 3. [HIGH] R-03 — Ukuran Area Sentuh Mobile (Tap Target < 44px)
- **Komponen**: `BracketView.tsx` (baris 275–290: tombol Zoom `+` dan `-`, baris 246–257: tombol pill Kategori)
- **Alasan**: Tombol kontrol zoom (`+` dan `-`) serta tombol kategori memiliki tinggi area sentuh sekitar 28px–32px (`py-0.5` dan `py-1.5`), di bawah standar target sentuh minimum mobile 44px (R-03).

### 4. [MEDIUM] R-06 — Penggunaan Emoji OS Default pada Mode Switcher
- **Komponen**: `BracketView.tsx` (baris 224, 235)
- **Alasan**: Tombol tab menggunakan emoji sistem mentah (`🏆` dan `📊`) yang tampil tidak konsisten antar sistem operasi (Windows vs iOS vs Android), alih-alih menggunakan vektor SVG inline yang terkurasi dan selaras dengan icon system klub tenis.

### 5. [LOW] C-4 — Indikator Geser Horizontal (Mobile Affordance)
- **Komponen**: `BracketView.tsx` (baris 316)
- **Alasan**: Kanvas bagan memiliki lebar minimum 860px di dalam kontainer `overflow-x-auto`, namun belum memiliki visual affordance atau badge panduan ("Geser ke samping untuk melihat babak berikutnya") pada layar ponsel kecil, sehingga peserta baru mungkin tidak menyadari bagan dapat digeser.
